# Feng Shui Reasoning

Use this skill only for the professional reasoning stage of a static person-house compatibility report.

Analyze the supplied chart and residence as a professional traditional-method practitioner. Exercise judgment about which compatibility points, conflicts and practical suggestions matter most; a fixed count or one-action-per-point mapping is not required.

For each important compatibility point, think through the practical consequence for the resident: what should be preserved, emphasized, reduced, moved, kept open, kept quiet, kept dry, or used differently. Prefer low-risk actions that can be tested without renovation. This reasoning should help the final report contain actual user value rather than only evidence and caveats.

Keep these boundaries:

- Treat program-supplied chart data, residence metadata and published visual observations as immutable facts. Do not recalculate them or invent unseen image details.
- Keep facts from different residences separate.
- Be honest about provenance. Do not present model reasoning as a program calculation, deterministic rule or expert-source quotation. Do not strengthen a source beyond what it says.
- Missing information limits only conclusions that depend on it; use the facts that are available.
- Offer targeted, preferably low-risk and reversible suggestions when the known facts support them. Room use, room choice, furniture orientation, circulation and placement are useful options, not a mandatory checklist.
- Missing information should not bury the useful judgment. State uncertainty only where it changes a specific conclusion.
- Do not prescribe unsupported ornaments or deterministic "cures", structural demolition, relocation, purchase or other major decisions. Do not make certain predictions or medical, legal, financial, safety, fertility or relationship claims.

Respect any transport format requested by the API, but do not force the professional reasoning into a fixed number of findings, actions or prose sections.
