# 八字排盘竞品对标记录

> 来源：问真八字网页排盘 `https://pcbz.iwzwh.com/#/paipan/index`，2026-09-01 只读抓取。该页面需要 JavaScript；本记录只使用公开首页与前端资源中可确认的产品边界，不复制其实现代码，不声称已经完成结果一致性。

## 已确认的问真能力边界

公开资源显示，问真网页排盘不是单一“四柱表”，而是把排盘拆成多类能力接口和页面入口：

- 基础八字排盘：出生日期、时辰、真太阳时等参数进入基础命盘计算。
- 干支关系：独立请求干支合冲刑害等关系。
- 格局判断：独立请求格局相关结论。
- 流年神煞：独立请求流年层面的神煞信息。
- 流通/五行相关：独立请求五行流通类信息。
- 农历换算：独立请求公历/农历相关转换信息。

这说明我们的产品不能只停留在四柱、十神、藏干这些展示字段；需要把“基础排盘、关系、格局、神煞、动态运势、参数版本”都做成可复算模块。

## 问真对照原则

1. 对照样例必须来自用户提供的截图、人工录入结果，或真实浏览器自动化采集；不能根据我们自己的引擎结果反推“期望值”。
2. 每个样例必须保存：出生日期、时间、地点、经纬度/是否真太阳时、性别、日界线、日历类型、问真输出截图或人工摘录。
3. 差异报告要分级：输入参数差异、历法/节气差异、真太阳时差异、起运算法差异、展示字段差异。
4. 当前已有 6 条真实问真截图哈希样例通过本地差异报告，覆盖普通专业表、立春边界、23 点子初换日、乌鲁木齐 `dstPolicy: ignore`/西部经度、农历闰四月，以及公开可采集的流年/流月动态盘。产品可以说“已有真实问真样例进入自动化对照，6/6 的四柱及已断言专业字段通过”，但不能说“与问真完全一致”。真太阳时仍存在问真显示分钟与当前 NOAA 近似算法相差 1 分钟的样例，当前记录为显示/算法差异，未硬编码追平。
